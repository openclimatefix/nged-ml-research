# Experiment 685: event table on the final-test window (data product)

**The event table finds 15 candidate events from 2026-06-16 onward and none of the priority transfers between `time_series_id` 13 and 16 in July or August.** Every row is a candidate, never a label. The tables are private: `data/ml-experiments/00685-event-table-on-the-final-test-window-all-primaries/event_table/` (`candidate_events.parquet` and `.csv`, `SUMMARY.md`, `reproduction_gate.json`).

- **Priority rows.** No transfer between id 13 (D18) and id 16 (D14) in July or August 2026. No event at id 11 (D4) in September. One event at id 18 (D16) in October: a solo fall of 0.75 MW (2.7 noise units) from 2026-10-04, open at the end of the window. So the one-year-backtest flags on ids 13, 16, 11 and 18 are not explained by an event the table can see in those months.
- **One open edge transfer.** From 2026-10-26 17:30 UTC D18 (id 13) falls 1.31 MW (8.2 noise units) and D14 (id 16) rises 0.71 MW; both are open at 2026-10-31.
- **Method.** E1-J-sym of experiment 680, no parameter changed, on the whole panel from 2022-01-01. Noise units and common-median scales are fixed on the data before 2026-07-01.
- **Weather at lag-free forecast time.** ERA5 2 m temperature (extended to 2026-10-31 from ARCO-ERA5, the same stage-1 box, 1.6 MB, hours after 2026-06-30 are ERA5T) and CAMS irradiance, both past weather, so not available at forecast time. The last half-hour (2026-10-31 23:30) has no forecast because ERA5 ends at 23:00.
- **Reproduction.** Arm C's 2026-06-01 cut matches experiment 327's stored forecast exactly (0 MW at all 15 series). With the window blanked, the pipeline reproduces experiment 680's 249 stored events exactly. With the window included, 187 of the 249 match and 62 stored events are replaced by 51 new ones (mostly small solo shifts, spread over every Primary): the slow level is refitted on the longer record, which moves borderline events. Treat events starting before 2026-07-01 as possibly changed by the extension.
- **Fetch.** Only `t2m`, August to October 2026, 1.6 MB, via `e00685_fetch_era5.py` (the stage-1 fetch script with its span constants overridden).
- **Review.** One fresh Sonnet code review before the run found a blocking indexing bug, a slow-level length effect on the noise units (frozen on the old length now), and a wrong `dark` flag on half-hour rows (fixed); it also noted that a cut left unfitted would leave NaN, and no cut was skipped.
